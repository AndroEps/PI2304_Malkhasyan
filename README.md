## Основные понятия

**Системы контроля версий** — программные инструменты для управления изменениями в исходном коде с течением времени.

**Git** — система управления версиями с распределённой архитектурой. Каждая рабочая копия сама по себе является репозиторием.

**GitHub** — облачная платформа для хранения репозиториев и командной работы над проектом.

**Репозиторий** — виртуальное хранилище проекта.

**Коммит** — «снимок» текущего состояния файлов проекта.

**Ветка** — указатель на один из коммитов. Позволяет вести параллельную разработку.

**Push** — отправка локальных изменений на удалённый репозиторий.

**Pull** — загрузка изменений из удалённого репозитория в локальный.

## Использованные команды

```bash
# Настройка
git config --global user.name "Malkhasyan Andranik"
git config --global user.email malhasanandranik111@gmail.com

# Создание репозитория
git init

# Работа с файлами
git add README.md
git status
git commit -m "init: add readme file"

# Ветки
git branch lab2-branch
git checkout lab2-branch
git merge lab2-branch

# Удалённый репозиторий
git remote add origin https://github.com/AndroEps/PI2304_Malkhasyan.git
git push origin master:main
git pull origin main:master
```
